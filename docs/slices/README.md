# The slices

A slice is a thin piece of the world taken through every layer, from sources and records through
validation and the build to the viewer, with criteria that say when it works and a test for each
([CONTRIBUTING.md](../../CONTRIBUTING.md#larger-work-slices)). Each document here says what its
slice added, its pass criteria and where each is tested, the decisions behind it, its limitations
and what it left for later.

They were written as each slice was built, and are the record of how the world came to be as it
is. Later slices changed some of what earlier ones built; each says so, and where two differ, the
later one describes the current build. The current design is in [WORLD-MODEL.md](../WORLD-MODEL.md)
and [STRUCTURE.md](../STRUCTURE.md).
